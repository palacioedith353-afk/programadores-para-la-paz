El login permite identificar a un usuario antes de darle acceso a una aplicación. Algunas rutas deben estar protegidas porque contienen información privada o funciones importantes. Solo los usuarios autorizados deben acceder a esas opciones. Esto ayuda a mantener la seguridad del sistema. No se deben exponer públicamente contraseñas, documentos de identidad, teléfonos, direcciones, tokens, claves de API ni otros datos sensibles de la comunidad.
